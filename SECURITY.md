# Report a security issue

Use GitHub's **Security → Report a vulnerability** if private reporting is
available. Otherwise, open an issue asking for a private reporting channel
without including sensitive details.

Include the affected Radio+ version and a minimal example of the problem.
Do not post exploit details, credentials, private keys, personal information
or full device dumps in a public issue.

Radio+ is a radio app, not a vehicle safety system. Do not rely on it for
safety-critical functions.
