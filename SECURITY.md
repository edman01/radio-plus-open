# Security reporting

This is experimental software with a device-specific vendor integration, not an
audited safety component. Do not rely on it for vehicle safety functions.

For a suspected vulnerability, use GitHub's **Security → Report a vulnerability**
if private vulnerability reporting is enabled. Do not put exploit details,
credentials or private device data into a public issue. If private reporting is
unavailable, open a non-sensitive issue asking for a reporting channel only.

Reports should include the affected version and a minimal reproduction with
synthetic data. Do not attach proprietary firmware, full device dumps or private
keys. This project does not promise a fixed response time or security certification.
